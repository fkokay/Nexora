# Tedarikçi teklifleri

`PurchaseSupplierQuotesPage.tsx` API isteklerini ve sayfa durumunu yönetir. `components/` altındaki bileşenler liste başlığını, filtreleri, sonuçları, sayfalamayı ve seçili teklif ayrıntılarını yalnızca kendilerine verilen props ile sunar. Ortak veri tipleri `types.ts` içindedir.
